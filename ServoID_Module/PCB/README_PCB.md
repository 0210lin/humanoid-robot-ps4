# ServoID 模組 電路板(KiCad)

2 層板,SMD 零件全放正面(JLCPCB 代焊單面),SuperMini 直接焊在板上,3S / 2S 共用。

## 規格

| 項目 | 內容 |
|---|---|
| 電池 | 2S / 3S 共用(約 6~12.6 V),兩個焊點 BAT− / BAT+ |
| 保險絲 | SMD 1206,5 A,串在電池 + 之後(馬達堵轉電流可能超過,樣品請測) |
| 降壓 | AP63205WU-7(固定 5 V、2 A、輸入 3.8~32 V),L=4.7 µH、輸入 10 µF/25 V、輸出 2×22 µF、自舉 100 nF(照資料手冊 DS41326 Rev.2 Table 3) |
| 主控 | ESP32-C3 SuperMini,兩排孔中心距 15.24 mm、腳距 2.54 mm,共 16 孔;用到:5V、GND、GPIO7(TX)、GPIO6(RX)、GPIO3(電池偵測) |
| 馬達焊點 | 3 個,順序 **GND(黑)/ PWR(紅)/ SIG(白)** |
| 鎖孔 | 4 個 M3(孔徑 3.2 mm),間距 **24 mm × 整數**(C 版 24×40,A 版 24×43),離邊 3.5 mm,不接地 |
| 電源保護 | D3(SS14)擋 USB 倒灌;USB 和電池可同時接 |

## 版本比較

| | A 寬鬆 | C 緊湊(推薦) |
|---|---|---|
| 板子 | 31 × 50 mm | 31 × 47 mm |
| DRC | 0 違規、0 未連接 | 0 違規、0 未連接 |
| 佈線 | 線段 133 條 | 線段 76 條(轉彎少、較直) |
| 降壓 SW 迴路 | 5.9 mm | 5.9 mm |
| 零件間距 | 比較鬆,好手焊除錯 | 較密,靠代焊 |

B(緊湊但線彎)和 D(C 的位置、間距放寬到 0.3 mm)也產生並檢查過,沒有勝過 C,所以沒有輸出下單檔。

## 檔案

- `ServoID_A.kicad_pcb`、`ServoID_C.kicad_pcb`:用 KiCad 10 開。
- `fab_C/`、`fab_A/`:`*_gerber.zip`(板子)、`*_CPL.csv`(零件位置)、`*_BOM.csv`(零件清單,LCSC 料號欄空白)、`*_print_1to1.pdf`(1:1 列印)、預覽圖。
- `layout_*.py`、`build.py`、`autoroute.py`、`run_variants.py`、`export_fab.py`:產生板子的腳本(換版本改 `layout_*.py`)。

## 下單前請你做的事

1. **用 1:1 列印檔對孔位**:`fab_C/ServoID_C_print_1to1.pdf` 用 100% 比例(不要縮放)印出來,把真的 SuperMini 的排針放上去,看 16 個孔是不是都對得到。孔中心距 15.24 mm 是我從商品圖上讀的,不是實測。
2. **確認腳位順序**:SuperMini 左排由上到下 5、6、7、8、9、10、20、21,右排 5V、GND、3V3、4、3、2、1、0(USB 朝上、從正面看),對照你手上那片板子上印的字。
3. **在 JLCPCB 的零件庫選料號**:BOM 的 LCSC 欄是空的,我沒有查證料號和現貨。依 BOM 的規格選:SS14(SMA)、1N4148W(SOD-123)、1206 保險絲 5 A 快斷、4.7 µH 屏蔽電感(4×4 mm,飽和電流 ≥ 2.7 A、DCR < 100 mΩ)、10 µF 25 V 以上 1206 陶瓷、22 µF 0805 陶瓷、AP63205WU-7。
4. **預覽零件位置與方向**:JLCPCB 上傳 CPL 後,有些零件(特別是 SOT/TSOT、二極體)的旋轉角度可能和他們的庫不同,要在預覽圖裡逐一看,有錯就改旋轉。
5. 這是第一版,建議打 5 片(最小量)先測。

## 還沒做的事

- 沒有 KiCad 電路圖(.kicad_sch):板子上的網路名稱是從我的連線表直接產生的,已用 DRC 檢查沒有短路、沒有未連接,並對照過電路圖逐腳核對,但沒有做 ERC。
- 沒有實機測試;降壓電路的電容耐壓、電感選型、保險絲電流都需要樣品驗證。
- 電池接上瞬間的電壓突波(長線)可能超過 25 V,這版沒有加 TVS。

## 版本 E(防反接 + 排針電池焊點)
- `layout_E.py`:C 版 + Q1 AO3401A(SOT-23,C15127)串在保險絲之後;R6/R7 100k 分壓做閘極偏壓(滿電 12.6 V → Vgs ≈ -6.3 V,低於 ±12 V 上限)。
- 電池焊點:2.54 mm 間距、1.0 mm 孔、2.0 mm 焊盤(排針),標示 − / + 放在焊點下方。
- AO3401A 資料表(AOS Rev 3.1):Vds -30 V、Vgs ±12 V、Id -4 A(25°C)/ -3.2 A(70°C)、Rds(on) < 50 mΩ @ -10 V、< 60 mΩ @ -4.5 V、Vgs(th) -0.5~-1.3 V。
- 限制:MOSFET 持續電流 ~3–4 A,比保險絲 5 A 小;單顆伺服設定 ID 沒問題,不要拿來接多顆伺服長時間滿載。
- Q1 腳位(1=G、2=S、3=D)為 SOT-23 通用腳位,下單前請對一次資料表第 1 頁的 Top View 圖。
- 執行:`python run_variants.py E`、`python export_fab.py E`(DRC 0 項,0 條未連接)。
