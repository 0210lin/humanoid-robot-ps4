## 組裝(SMT)/ Assembly
- 只貼**頂層(Top side)**,18 顆 SMD 零件:C1 C2 C3 C4 D1 D2 D3 F1 L1 Q1 R1 R2 R3 R4 R5 R6 R7 U1。
- **不要貼:** U2(ESP32-C3 SuperMini 模組)、J1(電池焊點)、J2(馬達焊點)、H1~H4(M3 鎖孔)。這些是通孔焊盤 / 孔,由客戶自己焊。
- 二極體 D1 D2 D3 有極性:組裝圖上紅色粗線那端是陰極(有橫線端)。U1、Q1 的 1 腳位置見組裝圖(紅點)。
- 零件規格見 `02_BOM_零件清單.csv` 的 Spec 欄。LCSC 料號欄已填 JLCPCB / LCSC 料號(C 版實際下單、測試可用的那一組;Q1 = C15127 是這版新增的);給其他廠商時請依 Spec 欄對應。
- 零件位置檔 `03_CPL_零件位置.csv`:座標單位 mm,Y 軸朝上(KiCad 輸出格式),Mid Y 為負值是正常的。
- **旋轉角度已改成 JLCPCB 零件庫的方向:** Q1(SOT-23):KiCad 180° → 檔案內 0°;U1(TSOT-23-6):KiCad 0° → 檔案內 270°。其他零件是 KiCad 原始角度。上傳後仍請在零件擺放預覽圖上對照 `04_組裝圖` 確認 1 腳(紅點)位置;若給其他廠商,請以 `04_組裝圖` 的方向為準。

## 這一版和 C 版的差別 / Changes from version C
- 新增電池防反接:Q1(P 通道 MOSFET AO3401A,SOT-23)串在保險絲之後的正極路徑,R6 / R7(100 kΩ)分壓做閘極偏壓。電池接反時 Q1 不導通,板子和馬達都不會通電。
- 電池焊點改成 2.54 mm 間距、1.0 mm 孔、2.0 mm 焊盤(可以直接焊排針或電線),標示 − / + 印在焊點下方。
- Q1 持續電流約 3~4 A(比保險絲 5 A 小):單顆伺服編 ID 沒問題,不要接多顆伺服長時間滿載。
