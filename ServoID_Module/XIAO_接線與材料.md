# XIAO ESP32-C3 版:接線表與材料清單

電路圖:[`schematic_xiao.png`](schematic_xiao.png)(向量版 [`schematic_xiao.svg`](schematic_xiao.svg))。
韌體編譯目標:`esp32:esp32:XIAO_ESP32C3:CDCOnBoot=cdc`(腳位:D5 = TX、D4 = RX、D1 = 電池偵測)。

> 電路和韌體都**還沒有在實機上驗證**。第一次通電請照 `README.md` 的順序,先用一顆**不要的馬達**。

## XIAO ESP32-C3 的腳(USB-C 朝上看)

| 左排(由上往下) | 右排(由上往下) |
|---|---|
| D0(GPIO2) | **5V** ← 電源輸入 |
| **D1(GPIO3)** ← 電池偵測 | **GND** |
| D2(GPIO4) | 3V3 |
| D3(GPIO5) | D10(GPIO10) |
| **D4(GPIO6)** ← 匯流排 RX | D9(GPIO9) |
| **D5(GPIO7)** → 匯流排 TX | D8(GPIO8) |
| D6(GPIO21)**不要用** | D7(GPIO20)**不要用** |

- 用到的腳:左排 **D1、D4、D5**,右排 **5V、GND**。**板子上有印腳位名稱,請以板子上的字為準**(我是依 Seeed 的腳位圖,沒有拿到實物)。
- **不要接 D6 / D7**:那兩支是開機序列埠,開機訊息會跑到馬達匯流排上。
- XIAO 買來通常附排針但**沒有焊**,插麵包板前要先把排針焊上去。

## 材料清單(做 1 個;零件很便宜,建議每樣多買 1~2 份備用)

| 項目 | 數量 | 規格 | 備註 |
|---|---|---|---|
| Seeed **XIAO ESP32-C3** | 1 | | 要自己焊排針(通常附) |

## 重要的注意事項

- **馬達電流不要走麵包板的電源軌**(麵包板接點只能承受約 1 A):馬達的電源和地要走**粗線**,從接線端子直接拉到馬達接頭,圖上紅線那條。
- **麵包板上只放小電流的東西**:降壓輸出、XIAO、二極體、電阻。
- **電池只能用跟馬達相符的**(7.4 V 的馬達接 2S,12 V 的接 3S),網頁會警告但擋不住,見 `README.md`。
- **二極體不要接反**。
- **第一次通電順序**:先只接 USB 測 WiFi 和網頁 → 降壓**單獨**通電調到 5.0 V(固定 5 V 的也要量) → 接電池(不插馬達)確認電壓顯示 → 量 Sig 空閒電壓約 4.0~4.2 V → 才插不要的馬達。

## 之後想要做成一塊板子時

材料基本一樣,但降壓模組改成降壓晶片(約 5×5 mm),電阻、二極體改貼片(0603 / SOD-123),XIAO 用排針焊在板子上。要等這個麵包板版驗證通過再做。
