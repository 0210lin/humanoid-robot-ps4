# 機器人(HurtMaker)PS4 遙控改裝

把原本的 Kondo 遙控器換成 PS4 手把。動作邏輯和原本**完全一樣**,只換了按鍵的來源。

```
PS4 手把 ──藍牙──> ATOM Lite(ESP32) ──UART(G26 → D8)──> Arduino Micro ──Serial1(500000)──> 伺服馬達
```

> 這份資料夾是從 `原版/` 改出來的,`原版/` 完全沒有動,隨時可以拿回去用。
> **還沒有在這台機器人上實際測試過**(沒有接機器人),編譯與動作邏輯比對都過了,但接線、配對、動作要你實測。見最後的「還沒驗證的事」。

## 資料夾說明

| 資料夾 / 檔案 | 用途 |
|---|---|
| `Micro_Robot/` | 燒錄到 **Arduino Micro** 的主程式(已整理) |
| `ESP32_PS4_Bridge/` | 燒錄到 **ATOM Lite**,讀 PS4 手把並送給 Micro |
| `ESP32_GetMAC/` | 一次性小工具:查 ATOM Lite 的藍牙 MAC |
| `Tools_MotorAdj/` | 馬達調整工具 **MotorAdjPlus**(電腦端,需要 Java)。雙擊 `MotorAdjPlus.jar` 開啟 |
| `Tools_Arduino/` | `arduino-cli.exe`(編譯、燒錄用) |
| `安裝.bat` | 第一次在新電腦用:自動檢查並安裝 Java、arduino-cli、Arduino AVR 支援(需要網路) |
| `一鍵更新動作.bat` | 把 `Tools_MotorAdj\motor.h` 複製進 `Micro_Robot`,編譯並燒錄 |

### Micro_Robot 內的檔案
| 檔案 | 作用 | 要不要改 |
|---|---|---|
| `custom.ino` | **按鍵 → 動作**對照表(搖桿範例也在這裡,預設全部關閉) | 想改動作就改這裡 |
| `motor.h` | 所有動作幀資料(74 幀,由 MotorAdj 產生) | 用 MotorAdj 產生,不要手改 |
| `pad.ino` / `pad.h` | 從 ATOM Lite 收按鍵與搖桿、按鍵位元定義 | 一般不用改 |
| `Micro_Robot.ino` | 馬達通訊、電腦通訊協定 | 一般不用改 |
| `custom.h` | 函式宣告 | 不用改 |

### 這次大改拿掉了什麼
原版的 `MainBoard_extend_micro` 還有:Kondo 接收器(`IcsSoftSerialClass`)、I2C 手把、超音波 / 紅外線 / 加速度計感測器、計時器中斷、BT 與自動模式。這台都沒有用,**全部移除**。程式空間從原本約 93% 降到 **85%**,每個動作幀約佔 156 位元組。

## 第 0 步:確認硬體

- **M5Stack ATOM Lite**(ESP32-PICO-D4,有傳統藍牙,可配對 PS4 手把),一台機器人一個。
- Arduino Micro 已經在你的電路板上。
- 三條線:

| ATOM Lite | 你的電路板 |
|---|---|
| Grove 接頭的 **G26**(通常白線 = G26,黃線 = G32,請用三用電表或對照 M5Stack 官方圖確認) | **Arduino Micro 的 D8** |
| GND | GND(**一定要共地**) |
| 5V | 5V(給 ATOM Lite 供電;若電流不夠或不穩,改用 USB 另外供電) |

選用:Micro **D9 → ATOM G32**,讓手把燈條顯示連線狀態。沒接也能操作,只是燈條會一直閃黃。

**請你確認兩件事(我沒辦法從程式碼確認):**
1. 這份是照第一台的板子(CreatorArk 的 MainBoard / PCB X1 mini,D8、D9、D4 在 DIO 排針上)寫的。如果這台機器人的板子 D8 沒有拉到排針,要從 Micro 模組或板子上找到 D8 腳。拍一張板子的照片給我可以幫你判斷。
2. **把原本的 Kondo 接收器拔掉。** 它原本接在 D8 / D9 / D4(經過一顆轉換晶片),留著可能會和 ATOM Lite 搶 D8。
3. 請**不要**用板子的 4 pin「UART 接頭」,它是 Micro 的硬體 Serial1,已被伺服馬達通訊佔用。

## 第 1 步:安裝軟體

1. 第一次在新電腦:雙擊 **`安裝.bat`**(會裝 Java、arduino-cli、Arduino AVR 支援;已有的會略過)。
2. 要燒錄 ATOM Lite,另外需要 **Arduino IDE**(arduino.cc/en/software):
   - ESP32 支援:「檔案 → 偏好設定 → 額外的開發板管理員網址」加入
     `https://espressif.github.io/arduino-esp32/package_esp32_index.json`,然後「開發板管理員」搜尋 **esp32** 安裝 **2.0.17**(**不要用 3.x**,PS4 函式庫在 3.x 上有問題)。
   - PS4Controller 函式庫:`github.com/aed3/PS4-esp32` 下載 ZIP,「草稿碼 → 匯入程式庫 → 加入 .ZIP 程式庫」。
3. Micro 這邊不需要額外函式庫(舊的 `IcsSoftSerialClass` 已移除,`SoftwareSerial` 是內建的)。

## 第 2~4 步:讓 PS4 手把連上 ATOM Lite

**如果你想和第一台共用同一支手把:** `ESP32_PS4_Bridge.ino` 裡的 `PS4_MAC` 已經是第一台用的那個。這個 MAC 是「手把記住的主機位址」,PS4Controller 函式庫會把 ATOM Lite 的藍牙位址設成它。所以**第二個 ATOM Lite 直接燒錄這份程式,手把就不用重新配對**(同一時間只開一台機器人,兩台同時開會搶手把)。
**如果想要這台自己用一支手把,或兩台同時開:**

1. 開 `ESP32_GetMAC/ESP32_GetMAC.ino`,開發板選 **M5Stack-ATOM**,上傳,序列埠監控視窗(115200)記下 `ESP32 Bluetooth MAC: xx:xx:xx:xx:xx:xx`。
2. 用 **SixaxisPairTool** 把這個 MAC 寫進另一支 PS4 手把(Master 欄輸入、按 Update)。
3. 開 `ESP32_PS4_Bridge/ESP32_PS4_Bridge.ino`,把 `#define PS4_MAC` 改成這個 MAC,上傳。
4. 開序列埠監控視窗,按手把的 **PS 鍵**,手把燈會變成穩定亮,按按鍵會看到 `key=0x....`。

> 若沒有連上:確認 MAC 一致、手把電量足夠、Arduino core 是 2.0.x。

## 第 5 步:燒錄 Micro

兩種方式擇一:
- 雙擊 **`一鍵更新動作.bat`**(Micro 用 USB 接電腦,MotorAdj 要先中斷連線)。
- 或用 Arduino IDE 開 `Micro_Robot/Micro_Robot.ino`,開發板選 **Arduino Micro**,上傳。(Micro 的 pin 0/1 是硬體 Serial1,和 USB 分開,上傳時不需要拔線。)

燒好後開 Micro 的序列埠監控視窗(115200),手把連線後每 200 ms 會印一行,例如 `Buttons: UP  | LeftStick X=0 Y=95 ... | mode=1`,用來確認按鍵數值正確,最後的 `mode=` 就是目前的動作模式。按下 Options 進入遙控模式、以及切換 mode 的瞬間,也會單獨印一行 `MODE = 1` 或 `MODE = 2`。要關閉:`pad.h` 的 `PAD_DEBUG_PRINT` 改成 0。(接上電腦用 MotorAdj 時不會印。)

## 第 6 步:操作

1. 機器人上電,ATOM Lite 與 Micro 都會開機。
2. 按 PS 鍵讓手把連線。
3. 按 **Options** = START,機器人進入遙控模式並回站姿。
4. **按鍵對照**(PS4 按鍵 = 原 Kondo 按鍵,按鍵碼數值一樣)。原版程式沒有寫動作名稱,下面只列幀編號;哪一組是前進、後退、轉向,以機器人實際動作為準:

| PS4 | mode 1(一般) | mode 2 |
|---|---|---|
| ↑ | 幀 2→3 起步,然後 8→9→10→11 重複(走路中加按 L1 / R1,換成幀 48 / 49) | — |
| ↓ | 幀 2→3 起步,然後 4→5→6→7 重複 | — |
| ← / → | 幀 13 / 14 搭配 12 | 幀 63 / 64 搭配 62 |
| △ | 幀 20→21 | — |
| ✕ | 幀 18→19(按著) | — |
| ○ | 幀 31→32(按著) | 幀 68→69(按著) |
| □ | 幀 33→34(按著) | 幀 70→71(按著) |
| L1 / R1 | 幀 37→38 / 35→36(按著) | — |
| L2 / R2 | 幀 16 / 17 搭配 15 | 幀 67 / 66 搭配 65 |
| **L3**(按下左搖桿) | 幀 30,22,23,24 → 53(按著)→ 25 → 站姿(原本 ← + ↓) | 幀 52,55,56 → 57(按著) |
| **R3**(按下右搖桿) | 幀 30,26,27,28 → 54(按著)→ 29 → 站姿(原本 ○ + ✕) | 幀 52,58,72 → 73(按著) |
| **左搖桿前推 + △** | 幀 47,48 → 49(按著)→ 50,51(原本 □ + ✕) | — |
| **左搖桿左推 + △** | 幀 45 重複;按著 **△** 多一個幀 46(原本 △ + □,再加 R1) | — |
| ○ + △ | **先不用**(程式用註解留在 `custom.ino`) | — |
| ↑ + ← | **先不用**(程式用註解留在 `custom.ino`) | — |
| **Options** | 開始 / 回站姿(幀 1) | 回 mode 2 站姿(幀 60,61) |
| **Share** | 馬達全部放鬆 | 馬達全部放鬆 |

**切換 mode:** 「**右搖桿下推 + △**」按住約 **300 毫秒** → mode 2(原本 → + ↓);「**右搖桿上推 + △**」按住約 300 毫秒 → 回 mode 1(原本 ↑ + →)。切到 mode 1 手把震一下,切到 mode 2 震兩下。

按住按鍵動作會持續,放開會回站姿。**持續的條件是「只按著這個鍵」(`pad_getKey() == 那個鍵`):多按了別的鍵、或放開,就結束。**兩招必殺技(左搖桿前推 + △、左搖桿下推)和原本一樣不看這個。

**安全機制:** ATOM Lite 與 Micro 之間超過 0.3 秒沒收到資料,Micro 會當作「沒有按鍵」,動作停止。手把斷線也是同樣情形。

**和 Kondo 版的差別(要知道):**
- Kondo 接收器每 10 ms 回報一次,PS4 橋接是每 30 ms 一次(原本 100 ms,輕按一下會做兩圈,所以縮短了)。放開按鍵到動作停下來,最多多約 30 ms 加上正在做的那一圈。
- 動作播放時(`SetFrameRun` 會等整段播完)很快按一下又放開的鍵,Kondo 版會漏掉;PS4 版會記起來,等程式有空時補做一次。
- 組合鍵靠「按鍵位元同時為 1」判斷,PS4 的 D-pad 斜推會同時帶兩個方向,所以「← + ↓」、「↑ + →」可以用斜推。

## 第 7 步:修改 / 新增動作

雙擊 `Tools_MotorAdj/MotorAdjPlus.jar`(需安裝 Java)。它是原本的 MotorAdj 加上一些功能,**開啟時自動載入 `HurtMaker.config`**(要換預設檔:「路徑設定…」)。

- **改動作姿勢 → 燒進機器人:** 調整動作、按「寫入」把那一幀存進去,然後直接按「**更新到機器人(燒錄)**」。它會自動:**儲存設定(存回目前載入的設定檔,舊的備份在 `backup`)→ 轉換成 `motor.h`**(以前要自己按這兩個鈕)→ 中斷串口 → 備份舊 `motor.h` 並複製新的 → 編譯 → 燒錄到 Micro。MotorAdj 不用關。沒有變動時會直接略過(要強制重傳:按住 Shift 再按按鈕)。
  - 注意:畫面上改了但**還沒按「寫入」**的那一幀不會被存(跟原本的「儲存設定」一樣)。
  - 不想要自動儲存 / 轉換:在 `MotorAdjPlus.properties` 加一行 `autoSaveConvert=0`,就回到原本要自己按的做法。
  - 「儲存設定」「轉換設定」兩個按鈕還是在,可以另存到別的檔名。
- **「動作程式」分頁:** 直接改 `custom.ino` 裡每個 `case` 的動作與延遲時間(含「方塊編輯」、「檢查語法」、「自動對齊」、幀編號檢查)。改完按「更新到機器人」;編譯失敗會自動還原 `custom.ino`。右邊用 26 根長條圖顯示播放時每顆馬達的位置。
- **「+ 新增幀(74/90)」**(馬達參數分頁左下):在最後多一幀。新增後把它「寫入」,再按「更新到機器人」(會自動儲存、轉換)。Micro 程式空間目前 **85%**;每幀約 156 位元組,加到 90 幀約 92%。上限可在 `MotorAdjPlus.properties` 加 `frameLimit=` 修改。
- **其他功能:** 單動作迴圈時間自動 200 ms、捲軸微調(±)、各馬達範圍、復原 / 重做「寫入」、人偶模式修正、批量匯出 / 載入幀、「路徑設定…」、背景與外觀(科技風為預設)、「設定」分頁的狀態卡片與環境檢查(缺少 arduino-cli 時提示執行 `安裝.bat`)。用法和第一台的 MotorAdjPlus 一樣。
- **這台沒有的:** 機器人 3D 模擬(馬達參數分頁右下角的 3D 圖和「機器人 3D」分頁)。「動作程式」分頁的 3D 改回 26 根長條圖。
- **鏡像分頁:** 目前**沒有設定任何配對**(第一台的配對是那台機器人專用的)。要用就在「鏡像」分頁新增,馬達編號照這台的左右對稱關係設。
- **改按鍵對應:** 編輯 `custom.ino` 的 `custom_gamepadKeyFun()`,例如:
  ```cpp
  case PAD_BTN_CROSS:
    SetFrameRun(18, 100);      // 先播這一幀,等 100ms
    do {
      SetFrameRun(19, 20);     // 按住時重複播這一幀
    } while (pad_getKey() > 0);
    SetFrameRun(1, 150);       // 放開後回站姿
    break;
  ```
- 接上電腦用 MotorAdj 時,機器人會自動離開遙控模式。

### 搖桿(蘑菇頭)與 L3 / R3

PS4 的組合鍵比較難按,所以原本的幾個組合鍵換成搖桿 / L3 / R3(動作內容和原本一樣):

| 原本(Kondo) | 現在(PS4) |
|---|---|
| ← + ↓ | **L3** |
| ○ + ✕ | **R3** |
| □ + ✕ | **左搖桿前推 + △** |
| △ + □(再加 R1 → 幀 46) | **左搖桿左推 + △**(按著 **△** → 幀 46) |
| → + ↓ 按住 1 秒(到 mode 2) | **右搖桿下推 + △** 按住 300 毫秒 |
| ↑ + → 按住 1 秒(回 mode 1) | **右搖桿上推 + △** 按住 300 毫秒 |
| ○ + △、↑ + ← | 先不用(註解保留) |
| ↑ 走路中加按 L1 / R1(換幀 48 / 49) | 沒動,維持原樣 |

注意事項:
- **「搖桿 + △」要先推搖桿、再按 △。** 如果先單獨按 △,會先做 △ 自己的動作(幀 20→21,800 ms),搖桿再推就太晚了。程式裡 △ 單獨的動作在搖桿推在這幾個方向上時會自動略過。
- 左搖桿「下推」目前**還沒有動作**(留給之後的另一招),但手把的必殺技大力震動已經有了:下推 + △ 就會震。
- **「搖桿 + △」的動作,啟動之後只看 △ 有沒有按著**,搖桿可以放開(左搖桿前推 + △、右搖桿上 / 下推 + △ 都是);切換 mode 如果搖桿放開、△ 按到 300 毫秒,一樣會切換。左搖桿下推那個沒有按鍵,所以一直看搖桿有沒有還推著。
- 切換 mode 要按住約 300 毫秒(`custom.ino` 的 `SWITCH_HOLD_MS`,ATOM Lite 的 `SWITCH_HOLD_MS` 要同步改)。**和原本不同:** 切換之後如果還按著,只會播一次站姿幀,不會重複。
- 搖桿死區是 60(0~127),在 `custom.ino` 的 `STICK_DEAD` 改。

### 手把震動

| 情況 | 震動 |
|---|---|
| **左搖桿前推 + △ / 左推 + △ / 下推 + △(必殺技)** | **持續大力震**(小、大馬達都 255),放開就停 |
| **切到 mode 1 / 切到 mode 2** | **一下 / 兩下** |
| 連上手把 | 震一下 |
| 電量很低(深紅那一段)且沒在充電 | 每 20 秒短短兩下 |
| 按住 ○ □ R1 L1 | 輕輕的細震 |

- 必殺技震動的方向判斷和 `custom.ino` 一樣(死區 60,哪個軸推得多就算哪個方向),不用按 △ 的「左搖桿下推」單獨推不會震。
- **必殺技只有 mode 1 會震**,mode 2 這兩招沒有動作,所以不震。這要靠 Micro 把目前的 mode 回報給 ATOM Lite,**需要接那條選用的線:Micro D9 → ATOM G32**。沒接線時,必殺技不分 mode 都會震。
- **切換 mode 的震動:** 有接 D9 → G32 時以 Micro 回報的 mode 為準(最準);**沒接線時**,ATOM Lite 依手把動作推測(同樣的規則:右搖桿下推 / 上推 + △ 按住 300 毫秒),Micro 剛好忙著做別的動作沒有切換時,可能和實際不一樣。
- 強度、死區在 `ESP32_PS4_Bridge.ino` 的 `SPECIAL_STRENGTH`、`SPECIAL_DEAD` 改。**要重新燒錄 ATOM Lite 才會生效**(Micro 也要重新燒錄,才會回報 mode)。

`custom.ino` 的 `custom_stickUpdate()` 每圈更新 `LS_UP / LS_DOWN / LS_LEFT / LS_RIGHT / LS_DIR`(右搖桿 `RS_`),三組資料互相獨立:一般按鍵 `pad_getKey()`、推搖桿 `pad_getStick(PAD_LX / LY / RX / RY)`(-128 ~ 127,Y 向上為正)、按下搖桿 `pad_getStickButtons()`(`PAD_L3` / `PAD_R3`)。還沒用到的有:右搖桿左 / 右、左搖桿左 / 右、L3 + R3。

## 還沒驗證的事

- **沒有接機器人實測:** 程式編譯通過(Arduino Micro,85%),`custom.ino` 的 22 個按鍵分支和 128 筆 `SetFrameRun` 呼叫已和原版逐項比對一致,換成搖桿 / L3 / R3 的 6 個動作,幀順序與時間也和原本的組合鍵逐項比對一致,MotorAdjPlus 開起來看過畫面。但 ATOM Lite 配對、D8 接線、實際動作都沒有試過。
- **第一次測試請把機器人架空**,先試方向鍵和 Share(全部放鬆),確認按鍵反應正常再放地上。
- ATOM Lite 的 PS4 配對步驟和第一台相同,但我沒有在這個 MAC 的 ATOM Lite 上驗證「兩個 ATOM Lite 用同一個 MAC 共用手把」。
- 原版的 `HurtMaker.config` 與 `淳睿.config` 內容相同;這裡只放了 `HurtMaker.config`(及 `.offset`、`config.config`)。
